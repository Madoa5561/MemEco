FEATURES

macOS の心地よさを、Windows の作法で。

macOS のメモリ管理をそのまま真似るのではなく、Windows 11 が持つ ネイティブな仕組みに置き換えています。アプリを止めずに、必要なときだけ動きます。

メモリプレッシャー

空きメモリ・コミット・メモリ圧縮ストアから 0〜100% の「圧迫度」を算出。トレイの色とリングで一目でわかります。

macOS のメモリプレッシャー相当

EcoQoS で App Nap 相当

前面にないアプリを Windows 11 の効率モード（EcoQoS）と低めの優先度に。CPU を省エネ寄りに動かします。

アプリは止めません

ワーキングセットのトリム

圧迫度が「注意」以上のとき、対象アプリの作業領域を解放。解放した量は必ず実測して表示します。

見かけの数字は作りません

スタンバイリストの解放

管理者モードのときだけ、未使用のスタンバイメモリを解放（purge 相当）。標準モードでは安全にスキップします。

管理者モード限定

App Nap Plus

圧迫度が「危険」のときだけ、条件を満たす背面プロセスを一時停止。前面化・最大時間・終了時に必ず復帰します。

既定 OFF・上級者向け

全自動・3 プリセット

2 秒ごとに状態を判定し、必要なときだけ動きます。「やさしい / 標準 / 積極的」から選ぶだけ。

既定のままでも動きます

HOW IT WORKS

賢いのは、踏み込まないこと。

MemEco は「触ってはいけないもの」を先に決めています。迷ったら保護する。それが安全の基本です。

01

見張る

2 秒ごとにメモリの圧迫度を計測。プロセスの走査は数秒に 1 回、47 ms 程度で終わります。

02

判断する

圧迫度・前面／可視ウィンドウ・音声再生・アイドル時間から、本当に手を入れてよい相手だけを選びます。

03

必要な分だけ動く

EcoQoS → トリム → スタンバイ解放 → （任意で）一時停止。すべて元に戻せる操作です。

触らないもの

  • システムの中核プロセス
  • 前面のアプリ・可視ウィンドウ
  • 音声を再生中のアプリ
  • 管理者権限で動作中のプロセス
  • 起動 60 秒未満・子プロセス持ち
  • ユーザーが指定した除外リスト

必ず戻す

  • 一時停止は前面化で即復帰
  • 最大時間を超えたら強制復帰
  • アプリ終了・設定 OFF でも復帰
  • 優先度は元の値に戻す
  • 停止中のまま放置しない

守る時間

  • 全画面ゲーム・プレゼン中は操作休止
  • 例外が出てもループを止めない
  • 権限がない操作は静かにスキップ
  • ログに残して原因を追える

FAQ

よくある質問

管理者権限は必要ですか？

基本的な機能（EcoQoS・トリム）は標準ユーザーでも動作します。スタンバイリストの解放だけが管理者権限を必要とします。

メモリ圧縮はしてくれますか？

Windows には標準でメモリ圧縮（Memory Compression）があります。MemEco はそれを監視・表示し、追加の解放を行います。OS の圧縮機能を置き換えるものではありません。

アプリが止まったり、動作が重くなったりしませんか？

EcoQoS はアプリを停止せず、CPU の使い方を省エネ寄りにするだけです。一時停止（App Nap Plus）は既定で OFF で、「積極的」プリセットで有効にした場合のみ動作します。

ウイルス対策ソフトに誤検知されませんか？

コード署名は行っていません。ソースコードは MIT ライセンスで公開しています。配布 exe は GitHub Actions でビルドした成果物で、SHA-256 を Releases に添付しています。

アンインストール方法は？

トレイメニューから終了し、Windows の「アプリと機能」または設定画面の「スタートアップ」から自動起動を外してください。スクリプト版（install.ps1 / uninstall.ps1）も同梱しています。

Windows 10 でも使えますか？

対象は Windows 11（Build 22000 以降）です。EcoQoS など Windows 11 の API を前提にしています。
